# 내 가계부

뱅크샐러드에서 내보낸 엑셀(.xlsx)을 올리면 생활비, 고정비, 눈에 띄는 지출을 보여주는 개인용 대시보드입니다.

- 엑셀은 브라우저 안에서만 읽고 이 브라우저의 저장소(localStorage)에만 남습니다. 서버로 보내지 않습니다.
- '가계부 내역' 시트만 읽습니다. '뱅샐현황' 시트(개인정보·신용점수)는 읽지 않습니다.
- 엑셀 파일은 `.gitignore`로 막아 두었습니다. 저장소에는 코드만 올라갑니다.

## 집계 기준
| 구분 | 기준 |
|---|---|
| 생활비 | 타입 '지출' 중 대분류 '금융'이 아닌 것 |
| 금융 지출 | 타입 '지출' + 대분류 '금융' (대출 상환·이자 등). 옵션으로 생활비에 합칠 수 있음 |
| 수입 | 타입 '수입' |
| 저축·투자 이체 | 타입 '이체' + 대분류 '저축'·'투자' |
| 집계 제외 | 그 밖의 이체 (내계좌이체, 카드대금 등). 이중 집계 방지 |
| 일회성 | 대분류 '여행/숙박' 또는 한 번에 설정 금액(기본 30만원) 이상 |
| 월말 예상 | 누적 생활비 ÷ 경과일 × 월 일수 (데이터 마지막 날이 그 달 안일 때) |
| 고정비 | 최근 3개월 매달 같은 내용으로 나간 지출, 금액 차이 20% 이내 |
| 눈에 띄는 지출 | 카테고리가 직전 3개월 평균의 1.5배 이상(5만원 이상) + 일회성 기준 이상 결제 |

## 파일
- `index.html` 화면 뼈대
- `styles.css` 디자인
- `calc.js` 집계 로직 (브라우저·Node 공용)
- `app.js` 화면 그리기, 업로드, 저장

빌드 과정이 없는 정적 사이트라 Vercel이나 GitHub Pages에 그대로 올리면 됩니다.
